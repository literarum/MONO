# Надёжность MONO по образцу гражданской авиации

Авиационная сертификация (DO-178C, ARP4754A/ARP4761) рассчитана на бортовое ПО: уровни DAL, покрытие
MC/DC, независимая верификация. Для настольного приложения это избыточно. Переносятся проверенные
принципы, а не формальности.

| Принцип авиации | Что это значит для MONO | Статус |
|---|---|---|
| **Строгость по последствиям отказа** (DAL A–E выводится из тяжести отказа) | Путь записи — «уровень A»: потеря записи необратима. Интерфейс и экспорт — «уровень C–D» | Запись покрыта E2E в браузере, тестами восстановления и живучести; косметика — юнит-тестами |
| **Иерархия оповещений EICAS** (warning → немедленное действие, caution → осведомлённость, advisory → сведения) | Предполётная проверка: красный блокирует запись, жёлтый — ограниченная возможность, голубой — сведения | Реализовано: `backend/local/preflight.mjs`, `public/preflight.js` |
| **Предполётный чек-лист** | Перед стартом записи проверяются ядро, папка архива, права записи, свободное место, копирование архива; в окне — доступ к микрофону и устройства | Реализовано, проверка блокирует старт только при WARNING |
| **Борьба с усталостью от сигналов** | Сигналить только о том, что требует действия; подтверждать сигнал порогом | Предупреждение о перегрузке — от 3 перегруженных сэмплов; о тишине — через 10 с |
| **Fail-operational / постепенная деградация** | Отказ подсистемы сужает возможности, а не останавливает работу | Нет системного модуля → запись через браузер; нет Groq → запись без расшифровки; сбой самой проверки не блокирует запись |
| **Резервирование и журнал** | Подтверждённые фрагменты, журнал восстановления, повторное воспроизведение после сбоя | Было в 0.4; дополнено компенсацией простоя воркера и запретом сна |
| **«Чёрный ящик»** | Локальный журнал событий без содержимого записей | `launcher.log`, коды диагностики захвата; структурированный журнал — в планах |
| **Стандартные формулировки** | Каждое сообщение: что случилось → что сохранено → что сделать | Словарь ошибок записи покрывает 30+ кодов |

## FMEA пути записи

| Отказ | Обнаружение | Последствие без защиты | Защита | Статус |
|---|---|---|---|---|
| Нет системного модуля записи | Возможности модуля | Каждая запись — ошибка | Автоматический переход на микрофон браузера | Реализовано, E2E |
| Пользователь долго думает над запросом доступа | Состояние разрешения | Обрыв старта через 10 с | До 120 с на ответ | Реализовано |
| Доступ к микрофону запрещён | Permissions API | Запись не начнётся | CAUTION с инструкцией в проверке | Реализовано |
| Микрофон молчит или выбран не тот вход | RMS < −50 dBFS 10 с | Пустая запись | Предупреждение во время записи | Реализовано |
| Перегрузка входа | ≥3 перегруженных сэмпла | Искажённая речь | Предупреждение во время записи | Реализовано |
| Мало места на диске | Свободное место на диске (statfs) | Обрыв посреди встречи | WARNING < 15 мин, CAUTION < 2 ч | Реализовано |
| Нет прав записи в папку архива | Проверка доступа на запись | Ошибка при первом фрагменте | WARNING до старта | Реализовано |
| Долгая операция блокирует ядро | Время обработки запроса | Ложная «потеря микрофона» | Компенсация простоя | Реализовано |
| Медленный диск или антивирус | Время сохранения фрагмента | Обрыв после 4 с задержки | Запас 30 с, очередь 15 фрагментов | Реализовано |
| Сон компьютера | Системные часы | Обрыв записи | Запрет простоя на время записи | Реализовано, не проверено на Windows/macOS |
| Закрытие окна | `beforeunload` | Обрыв браузерной записи | Подтверждение | Реализовано |
| Аварийное завершение процесса | Журнал при запуске | Потеря неподтверждённых фрагментов | Восстановление по журналу | Было в 0.4 |
| Разрыв в потоке WASAPI | Флаги буфера | Обрыв записи звука компьютера | Заполнение разрыва по времени QPC | Исправлено, **не скомпилировано** |
| Смена устройства по умолчанию | Уведомления о смене устройств | Обрыв записи | — | Открыто: продолжать на новом устройстве |
| Groq недоступен | HTTP 5xx/429 | Нет расшифровки | Повторы с паузой; запись не затронута | Было в 0.4 |
| Галлюцинации на тишине | Правило Whisper, фразы, повторы | Мусор в тексте | Фильтр, пропуск тихих окон | Реализовано |
