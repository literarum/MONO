## Global Constraints

- Windows 10 22H2 / Windows 11 x64; macOS 14.2+ Apple Silicon и Intel. Windows-only работа не закрывает контракт.
- Все 22 удаления выполняются по реестру R-001. Не удалять прочие декоративные тексты автоматически.
- Шкала расстояний: 4/8/12/16/20/24/32/40/48/64 CSS px; микрорасстояния 1/2 px только именованными токенами; высоты 40/44/48 px.
- Motion: 100–140 / 140–180 / 180–240 ms; prefers-reduced-motion обязателен; начальный blur фона меню 4 px.
- Темы dark/light; 390/768/1024/1440 CSS px; 200% zoom. Scrollbars со стрелками кастомные во всех внутренних областях.
- Постоянное аудио и текст не зависят от профиля браузера. Оригиналы неизменны. Миграция и перенос копируют, проверяют, затем переключают; источники не удаляются.
- Подтвержденный сегмент 2 s; сохранение означает durable commit. Четырехчасовой фактический прогон обязателен отдельно от синтетического.
- A/B сохраняет позицию до 100 ms; длительность производной до одного frame после учета padding. Речевой корпус: минимум 18 фрагментов, 3 на каждую из 6 категорий, 30–60 s; clean-speech WER ухудшение ≤1 п.п.; шумная категория должна улучшаться для автоматической рекомендации.
- Ключ: DPAPI CurrentUser/Keychain, без plaintext fallback; никаких ключей в browser storage, URL, logs, backup. Аудио в Groq только по явному подтверждению.
- Только loopback, Host/Origin/session/CSRF и безопасные пути. Proxy-контракты сохраняются, desktop-операции в proxy недоступны.
- Никаких публикаций, платных ресурсов, удалений существующих данных, изменения системных разрешений и использования учетных данных без соответствующего поручения.
- Репозиторий не Git: не создавать Git и не выполнять фиктивные commit-шаги. Контрольные снимки и ledger заменяют revision provenance, пользовательские изменения не перезаписываются.

## Test cycle shared by every implementation task

Каждый первый RED-шаг включает запуск именно команды тестов, указанной в этой задаче, до изменения реализации. Ожидается FAIL по названному нарушению контракта; сохранить raw log/exit и подтвердить, что запуск действительно обнаружил тесты. Для нового модуля missing import подтверждает только отсутствие модуля: после минимального появления интерфейса проверить, что правдоподобный неверный результат отклоняется тем же оракулом. Нельзя считать пустой набор тестов, stale snapshot или исключение setup доказательством поведенческого RED. Затем минимальная реализация, та же команда GREEN, соседняя регрессия, review и указанный black-box. Новые браузерные и нативные команды нельзя объявить пройденными по unit fixtures.

## Rollback and environment gaps

До изменения исходников — файловый checkpoint с SHA. Возврат выполняется только для наших файлов после сравнения текущего hash; новые пользовательские изменения не затираются. Источники миграции, исходная библиотека и существующий dist остаются. Рабочая библиотека новой схемы не открывается старым executable; для отката выбирается сохраненная исходная библиотека.

В этой среде подтвержден Windows host; доступ к Mac, signing credentials, разрешенному речевому корпусу и реальному Groq пока не подтвержден. Их отсутствие не мешает локальной реализации и детерминированным тестам, но не позволяет закрыть обязательные native/WER gates. Не запускать GitHub workflow или платные cloud macOS runners без отдельного поручения.
