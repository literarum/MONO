# Приёмка локальной поставки MONO

Текущий статус Windows: кандидат для проверок, не готовый производственный релиз.
Сборка EXE и перечисление устройств не подтверждают запись звука.
macOS остаётся обязательной отдельной поставкой; адаптер и проверки на Mac ещё
не завершены. Этот протокол не разрешает публикацию или использование ключей.

## Подготовка Windows

1. Использовать Windows 10 22H2 / Windows 11 x64. Зафиксировать версию ОС,
   модель аудиоустройств и SHA-256 всей проверяемой поставки.
2. Сохранить прежнюю поставку и архив. Выбрать отдельную папку данных для QA;
   не переносить единственную копию пользовательского архива в экспериментальную сборку.
3. Проверить пакет командой `python scripts/verify-package.py <папка> --require-node-baseline` на машине
   сборки. `--execute` применять к собственному доверенному EXE: выполняются
   встроенная проверка целостности и перечисление устройств без начала записи.
4. Повторить пользовательский запуск на чистой машине/VM без установленного
   Python, Node, .NET SDK и FFmpeg. Не отключать защиту Windows и не добавлять
   исключения ради прохождения проверки. Подпись издателя проверяется отдельно;
   контрольные суммы её не заменяют.

## Запуск и восстановление

- Двойной клик открывает одно окно; повторный клик не создаёт второй сервер.
  Во время старта/остановки повторный запуск показывает понятное состояние.
  При занятом порте не подключается к чужому серверу и не завершает его.
- Первый запуск без ключа позволяет выбрать архив и звук, пропустить облачную
  настройку, записать и прослушать материал. Ссылка на получение ключа понятна;
  без явного подтверждения ничего не отправляется провайдеру.
- Импортировать разрешённую тестовую запись; изменить текст; закрыть и снова
  открыть приложение. Хеш исходного аудио, исходный и исправленный текст
  должны сохраниться. Проверить экспорт в новую папку и обратный импорт.
- Прервать копирование архива. После запуска операция показана как прерванная;
  только явное продолжение копирует данные. Отмена сохраняет исходник и уже
  скопированные файлы. Повреждённый журнал требует явного восстановления.
- При недоступном диске/нехватке места/ошибке записи нет ложного подтверждения
  сохранения. После освобождения места доступно понятное восстановление.

## Настоящий звук

Проверять на разрешённом тестовом звонке; не записывать рабочие разговоры без
согласия. Для текущей USB-гарнитуры отдельно сверить обычное устройство Windows
и устройство связи: они могут отличаться, особенно для выхода MANGO Office.

| Режим | Наблюдаемая проверка |
| --- | --- |
| Микрофон | Слышна речь с выбранного USB-входа, проверен уровень и точное устройство |
| Система | Слышен тестовый звук из выбранного выхода, включая устройство связи |
| Вместе | Слышны обе стороны тестового звонка; нет пропавшей дорожки или удвоения |

Для каждого режима: запуск, пауза, возобновление, остановка, воспроизведение,
перезапуск приложения, точная длительность и хеши сохранённых сегментов.
Проверить отключение USB, смену устройства по умолчанию, запрет/возврат
разрешения и сон/пробуждение. Запись начинается только по действию пользователя.
Отказ ОС должен оставлять доступ к частичной записи и понятный способ повторить.

Провести четырёхчасовую запись с паузами: счётчик подтверждённых сегментов,
хеши, длительность/дрейф часов, память и свободное место. Завершить процесс
контролируемо на тестовых данных и проверить восстановление. Потеря любого
подтверждённого сегмента запрещает выпуск.

## Обработка и выпуск

- Прослушать до/после на общей временной шкале, начало/середину/конец и быстрые
  переключения. Проверить отсутствие двойного воспроизведения, щелчков,
  сокращения временной шкалы и незаметной смены выбранной версии.
- Реальную расшифровку проверять только после отдельного разрешения отправки
  тестового материала и использования ключа. Зафиксировать модель, выбранную
  версию аудио, запрос, стоимость/ошибки и сохранность результата после рестарта.
  Stub-провайдер не подтверждает качество речи или WER.
- На обеих темах, узком окне и 200% масштабе проверить навигацию, клавиатуру,
  фокус, меню/затемнение, списки и отсутствие перекрытий.
- Перед выпуском: полный A/B/C, независимый итоговый обзор, комплект лицензий,
  подпись владельца, проверка чистой машины и привязанный журнал доказательств.
  Публикация выполняется отдельным явно разрешённым действием.
- Откат: закрыть новый экземпляр и открыть сохранённую прежнюю поставку.
  Не удалять новый архив или частичную копию. Совместимость версии архива
  проверить на копии до переключения рабочего пользователя.

Для каждого пункта хранить команду/шаги, время, версию пакета, ожидаемый и
фактический результат. `NOT_RUN` и отказ — открытые ворота, не успешная приёмка.
