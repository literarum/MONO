# 30 механизмов надёжности и бесшовности — 18.11.2026

Цель: человек получает только функцию — «нажал и записалось, нажал и расшифровалось». Всё техническое MONO решает сам и говорит одной строкой, только когда это действительно нужно.

Обозначения: ✅ сделано и проверено (где именно — в столбце «Проверка»); 🟡 сделано, проверить можно только на настоящем ПК; ⏳ не сделано (с причиной).

## Что сознательно не сделано (⏳)

- **Включение отключённого микрофона** и **перезапуск службы Windows Audio**. Первое возможно только через недокументированный API, второе — только с правами администратора. Молча такое делать нельзя, поэтому MONO показывает точный путь к настройке.
- **Значок в трее** нужно проверять на настоящем рабочем столе.
- **Флаг `ES_AWAYMODE_REQUIRED`** (не давать компьютеру уснуть, если закрыли крышку). По сторонним данным, на ноутбуках с Modern Standby он не поддерживается [13]. Закрытая крышка — решение человека; MONO сохраняет записанное и предлагает продолжить.
