# MONO TRANSCRIBE — 200 доработок и улучшений

Дата: 17.11.2026. Дополняет `docs/qa/AUDIT-2026-11-17.md`: там дефекты, здесь развитие продукта.
Пункты, уже реализованные в коде, исключены. Уже есть: профили «Оригинал / Бережно / Выровнять голос /
Убрать ровный шум», предпрослушивание, редактор с версиями «оригинал/правка», поиск, скорость плеера,
переход к фрагменту по клику, экспорт TXT/MD/JSON/SRT/VTT/DOCX/PDF, корзина, перенос и резервирование
архива, онбординг.

**Метки.** Приоритет: **P0** — блокирует продакшн или даёт наибольший эффект, **P1** — высокий,
**P2** — средний, **P3** — полировка. Трудоёмкость: **S** — до дня, **M** — до недели, **L** — больше
недели. **[И]** — опирается на внешний источник (список в конце), **[Г]** — гипотеза, которую нужно
проверить замером на русском корпусе.

**Ограничения исследования.** Официальная документация Groq (`console.groq.com`) недоступна из сети
этой сессии, поэтому её параметры взяты из поисковой выдачи и сторонних страниц и требуют сверки. Данных
о качестве pyannote на русском не найдено — НЕТ ДАННЫХ ДЛЯ НАДЁЖНОГО ВЫВОДА. Влияние шумоподавления на
Whisper подтверждено одним бенчмарком, аффилированным с вендором.

## A. Запись и захват звука (1–24)

1. **Индикатор уровня до старта записи.** Живой метр выбранного микрофона в студии, чтобы проблемы
   было видно до нажатия «Запись». P0·S
2. **Предупреждение о тишине во время записи.** Если 10 с уровень ниже −60 dBFS — баннер «Микрофон
   молчит — проверьте выбор входа». P0·S
3. **Предупреждение о клиппинге.** Счётчик перегрузок уже передаётся (`clippedFrames`), но не
   показывается. Нужны красный индикатор и совет снизить усиление. P1·S
4. **Запись звука конкретного приложения на Windows** (Zoom, Teams, браузер) через
   `AUDIOCLIENT_ACTIVATION_TYPE_PROCESS_LOOPBACK`; режим исключения может убирать звуки самого MONO.
   Требует Windows 10 build 20348+. P1·L [И]
5. **Звук системы на macOS** через Core Audio process taps (`AudioHardwareCreateProcessTap`,
   macOS 14.2+; в источниках встречается и 14.4). Сейчас на macOS записывается только микрофон. P1·L [И]
6. **Две дорожки при записи встречи:** микрофон и система раздельно. Нативно это уже есть, нужно
   использовать: «Я / Собеседники» как готовая диаризация без ML. P0·M
7. **Подавление эха** в режиме «Микрофон + компьютер» без наушников: вычитать loopback-дорожку из
   микрофонной (AEC с опорным сигналом). P2·L [Г]
8. **Автостарт по голосу (VAD-триггер)** с предзаписью 2–5 с из кольцевого буфера. P2·M
9. **Автостоп после N минут тишины** с подтверждением и откатом последнего отрезка тишины. P2·S
10. **Маркеры «Важно» во время записи** — горячая клавиша ставит закладку на таймлайне; закладка
    переносится в транскрипт. P1·S
11. **Текстовые заметки по ходу записи** с привязкой ко времени. P2·M
12. **Глобальные горячие клавиши** (старт / пауза / стоп / маркер), работающие при свёрнутом окне. P1·M
13. **Значок в системном трее** с состоянием записи и быстрыми действиями. P2·M
14. **Выбор частоты и формата захвата** (16/48 кГц, моно/стерео) с подсказкой о размере файла. P3·S
15. **Оценка остатка свободного места** «хватит примерно на N часов» прямо в студии. P1·S
16. **Сжатие во время записи в Opus через WebCodecs** вместо 16-битного WAV: примерно в 10 раз меньше
    на диске. Проверять поддержку `AudioEncoder.isConfigSupported()`; поддержка Opus в WebCodecs для
    браузеров необязательна. P2·M [И]
17. **Пауза без записи тишины на диск:** хранить только маркер. Сейчас пауза занимает место и
    оплачивается при расшифровке. P1·M
18. **Мягкое восстановление после потери устройства:** при `DEVICE_LOST` продолжать запись на
    устройстве по умолчанию с маркером разрыва, а не останавливать её. P1·M
19. **Следование за системным устройством по умолчанию** при подключении гарнитуры (опция). P2·M
20. **Запись с нескольких микрофонов одновременно** — интервью с двумя петличками. P3·L
21. **Индикатор «Идёт запись» в заголовке окна и на панели задач** (бейдж, прогресс). P2·S
22. **Защита от сна системы во время записи:** Windows `SetThreadExecutionState`, macOS
    `IOPMAssertion`. Сейчас сон прерывает запись (`SLEEP`). P0·S
23. **Запрет закрыть окно во время записи** с диалогом «Остановить и сохранить?». P1·S
24. **Резервная копия незавершённой записи** в отдельную папку для параноидального режима
    (двойная запись). P3·M

## B. Звукообработка и DSP (25–48)

25. **Метрики качества записи после остановки:** громкость в LUFS, отношение сигнал/шум, клиппинг,
    процент тишины, с понятной оценкой («хорошо / тихо / шумно»). Анализ уже считает многое — нужно
    показать. P0·S
26. **Автовыбор профиля обработки по метрикам** с объяснением «почему». Сейчас все профили
    `recommended:false`. P1·M [Г]
27. **Цель громкости −16 LUFS для прослушивания**, отдельно от −19 для распознавания. P3·S [И]
28. **Двухпроходная нормализация везде.** Однопроходный `loudnorm` «качает» на файлах, обработанных
    заранее. Сейчас два прохода только в «Выровнять голос». P2·S [И]
29. **Шумоподавление RNNoise (`arnndn`) как отдельный профиль.** Внимание: по одному бенчмарку RNNoise
    0.2 ухудшил WER Whisper с 3,75% до 5,68%. Применять только для прослушивания, не для распознавания,
    пока нет своего замера. P2·M [И][Г]
30. **DeepFilterNet3 как «сильное» шумоподавление.** Около 40 мс задержки и в 7–11 раз больше CPU, чем
    RNNoise; для Whisper в том же бенчмарке эффект нейтральный. Только по явному выбору. P3·L [И]
31. **A/B-сравнение профилей вслепую** с выравниванием громкости, чтобы «громче» не казалось «лучше».
    P2·M
32. **Шумовой профиль по фрагменту тишины** («обучить шумоподавление на этих 2 секундах»):
    `afftdn` с параметрами профиля. P2·M
33. **Подавление гула 50 Гц и гармоник** (режекторные фильтры), с автоопределением. P2·S
34. **Де-эссер и подавление «п/б»-плевков** для близкого микрофона. P3·M
35. **Компрессор для тихой речи** — выравнивание диалога, где один говорит далеко. P2·M [Г]
36. **Срез длинной тишины для прослушивания** с переменной скоростью («умное ускорение»), без
    изменения оригинала. P2·M
37. **Удаление щелчков** (`adeclick`) и треска (`adeclip` для клиппинга). P3·S
38. **Независимая обработка дорожек** «Я / Собеседники» перед сведением. P2·M
39. **Автоматическое выравнивание громкости дорожек при сведении** (сейчас фиксированный запас). P2·S
40. **Визуальная волна и спектрограмма в редакторе** со звуком на наведении. P1·M
41. **Нормализация входного уровня в реальном времени** (мягкий AGC) — опционально, по умолчанию
    выключена, как сейчас. P3·S
42. **Определение реверберации** («запись в гулком помещении») с советом по размещению микрофона. P3·M
    [Г]
43. **Детектор музыки и фона** — пометка отрезков без речи. P3·M
44. **Ускоренный рендер превью только выбранного отрезка** вместо всей записи. P2·S
45. **Многопоточный рендер на многоядерных CPU:** параллельная обработка по сегментам с перекрытием.
    P2·M
46. **Кэш анализа по хешу источника,** чтобы повторное открытие было мгновенным. P2·S
47. **Корпус эталонных записей** (тихо / шумно / телефон / далеко) и автоматический замер WER для
    каждого профиля — основа для любых решений по DSP. P0·M
48. **Отчёт «что сделала обработка»** — графики до и после. P3·M

## C. Качество распознавания (49–74)

49. **VAD перед отправкой в Groq (Silero VAD v5):** не отправлять тишину, резать по паузам. Whisper
    галлюцинирует на тишине; VAD — самая частая рекомендация. Модель около 2 МБ, MIT, ONNX, меньше 1 мс
    на окно 32 мс на CPU. P0·M [И]
50. **Резка на сегменты по паузам, а не каждые 240 с:** меньше разорванных слов, а 0,8 с перекрытия
    станут не нужны. P0·M [И]
51. **Не отправлять фрагменты без речи** — экономия: минимум 10 с оплаты на запрос. P1·S [И]
52. **Фильтр галлюцинаций:** список типовых фраз («Продолжение следует…», «Субтитры сделал…»),
    обнаружение повторов, порог коэффициента сжатия, пометка «сомнительно» вместо удаления. P0·M [И]
53. **Использовать `no_speech_prob` и `avg_logprob` из `verbose_json`** для подсветки ненадёжных
    фрагментов. P1·S [Г: поля нужно сверить в ответе Groq]
54. **Словарь терминов и имён:** UI-список, из которого собирается `prompt`. Лимит prompt 224 токена,
    нужен счётчик. P0·S [И]
55. **Контекст из предыдущего сегмента в prompt** — опция с защитой от зацикливания повторов. P2·S [И]
56. **Даунмикс в моно 16 кГц FLAC перед Groq** — в разы меньше трафик и запросов. Проверить замером,
    что WER не меняется. P1·S [Г]
57. **Повтор сомнительных фрагментов на `whisper-large-v3` (не turbo)** — гибрид «дёшево, где уверены».
    P2·M [Г]
58. **Пословные метки времени** (granularity `word`, по выдаче поиска поддерживается) для караоке-
    подсветки и точного монтажа. P1·M [И: параметр сверить в документации]
59. **Пословная уверенность** в виде подчёркивания цветом. P2·M
60. **Автоопределение языка и смешанная речь** (ru/en термины) с выбором языка на запись. P1·S
61. **Перевод на английский** через эндпоинт перевода (если доступен для модели) или через LLM. P3·M
62. **Пунктуация и регистр для русского:** постобработка моделями `neuro-comma` (MIT) или
    `sbert_punc_case_ru`. P2·M [И]
63. **Обратная нормализация текста** («двадцать пятого» → «25-го», суммы, даты): NeMo WFST
    (русский поддерживается) или Thutmose Tagger. P2·L [И]
64. **Буква «ё»** — опциональная расстановка. P3·S
65. **Нормализация кавычек, тире и неразрывных пробелов** по русской типографике. P3·S
66. **Фильтр мусорных слов-паразитов** («э-э», «ну») как опция «чистовой текст» при сохранённом
    оригинале. P2·S
67. **Автоматическая замена по пользовательским правилам** (регулярки и пары «как распознано → как
    надо»), накапливаемая из правок. P1·M
68. **Обучение на правках:** частые исправления предлагать в словарь терминов. P2·M
69. **Склейка фрагментов на стыках сегментов** — устранение дублей и обрывов слов по пословным меткам.
    P1·M
70. **Перераспознать выделенный фрагмент** с другим профилем, словарём или моделью. P1·M
71. **Сравнение двух расшифровок** (diff) — до и после смены профиля. P2·M
72. **Оценка точности по выборочной вычитке:** пользователь правит 2 минуты, приложение оценивает WER.
