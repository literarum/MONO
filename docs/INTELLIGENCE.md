# Интеллект MONO — 18.11.2026

Принцип: MONO анализирует расшифровку **на компьютере** и подсказывает. В сеть уходит только то, что человек явно разрешил (аудио для расшифровки, текст для конспекта). Каждое правило консервативное: при сомнении MONO оставляет слова человека как есть.

## Что сделано

| # | Функция | Где | Как устроено | Проверка |
|---|---|---|---|---|
| 1 | **Конспект встречи**: итог, решения, задачи с ответственным и сроком, открытые вопросы, темы. У каждого пункта ссылка на время, щелчок по ней включает это место | `backend/groq/summary.mjs`, `backend/local/summary-routes.mjs`, редактор | Отправляется только текст, после отдельного согласия. Длинная встреча разбивается на части по ~14 000 знаков: сначала конспект каждой части, потом сведение в один [3][4]. Ответ в режиме JSON; модель без JSON-режима получает повторный запрос без него. Ответ проверяется: лишние поля отбрасываются, время не может быть больше длительности записи. | 8 | **Выученный словарь**: имена и термины, которые человек исправил вручную (PostgreSQL, Groq, Кузнецова), добавляются к подсказке следующих расшифровок, пока есть место. | 9 | **Чистый текст** при экспорте: убираются «э-э», «м-м», «это самое» и запинки («в в») | `cleanText` | Слова «вот», «там», «типа», «ну» в русской речи часто несут смысл (корпусное исследование ВШЭ [9]), поэтому остаются. ## Что сознательно не сделано (НЕТ ДАННЫХ ДЛЯ НАДЁЖНОГО ВЫВОДА)

- **Уверенность по словам.** Groq не возвращает вероятности по словам, только по фрагментам [6].
- **Автоматический конспект после каждой расшифровки.** Это ещё одна отправка текста; MONO спрашивает каждый раз.
- **Строгая схема `json_schema`.** Документация Groq заявляет поддержку для GPT-OSS [2], но разработчики сообщают, что схема игнорируется или возвращает 400 [2a]. Поэтому используется `json_object` и своя проверка ответа.
- **Пороги, подобранные на ваших записях.** Порог уверенности 0,37 и параметры пауз не проверены на размеченной выборке ваших встреч. Если отметок «сомнительно» слишком много или мало, порог нужно настроить.
- **Работа с Groq на реальном ключе.** В CI используется локальная подделка API. Формат ответа взят из документации Groq, но настоящий запрос из этой сессии не отправлялся.
