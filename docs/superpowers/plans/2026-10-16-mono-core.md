# MONO Core and Archive Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** R-018…R-022/R-033…R-035: независимый от браузера архив с защищенным локальным API и безопасной миграцией.
**Architecture:** Python worker — единственный writer SQLite/файлов; Node — валидирующий HTTP facade и клиент worker по приватным pipes. Метаданные versioned, chunks durable, индекс восстанавливаем из manifest/journal.
**Tech Stack:** Python sqlite3/unittest, Node HTTP/streams/node:test, stdio NDJSON, OS file locks.
**Spec:** ../../MONO-0.5-SPEC.md; 2026-10-16-mono-master.md.

## Global Constraints

Наследует master Global Constraints. Копировать существующий архив без удаления. Только loopback, session/CSRF, safe paths, без plaintext секретов; proxy mode не получает desktop routes.

## Review Focus

Crash между file fsync/rename/SQL commit, concurrent writers, старые optimistic versions, path reparse/symlink и исчезновение диска. Каждое проверяется реальной файловой fixture в owning task.

### CORE-1: приватный worker и browser session boundary

**Files:** Create backend/local/worker-client.mjs, backend/local/session.mjs, backend/local/routes.mjs, launcher/local_core/worker.py, launcher/local_core/protocol.py, tests/local-security.test.mjs, launcher/tests/test_worker.py; Modify server.mjs, healthcheck.mjs, launcher/mono_launcher.py, launcher/build_portable.py, tests/proxy.test.mjs.
**Interfaces:** worker messages `{v:1,id,method,params}` → `{v:1,id,result}` / `{v:1,id,error:{code,message,retryable}}`; stdout only NDJSON, max line 64 KiB, no audio/secret logs. `WorkerClient.call(method,params,{signal,timeoutMs=15000}):Promise<result>`, startup ready ≤25 s; EOF ends worker. Method allowlist only. `GET /api/local/session` returns csrf token only with session cookie; all private reads require session, mutations additionally X-Mono-CSRF + same-origin.

- [ ] RED: unknown method, oversize/malformed line, duplicate id, worker exit/timeout/cancel, pending calls on EOF. HTTP: wrong Host/Origin/Fetch-Site, absent cookie, absent/wrong CSRF, media GET authorization; proxy desktop endpoints return 404. Test session token never appears in URL or logs.
- [ ] Implement worker lifecycle mode `--core-worker`, fixed executable/args, pipe-only credentials. Bootstrap on top-level same-origin navigation: HttpOnly SameSite=Strict cookie scoped to session; foreign iframe/navigation cannot bootstrap with Sec-Fetch-Site=cross-site; bootstrap data no-store and JS csrf memory only. Remote proxy gates remain unchanged. Untrusted same-privilege local OS process is outside CSRF threat model, not claimed protected by a cookie.
- [ ] Run `node --test tests/local-security.test.mjs tests/proxy.test.mjs`; `python -m unittest discover -s launcher/tests -p test_worker.py -v`. Existing local HTTP tests acquire a real session instead of bypassing guards. Save RED/GREEN and fresh adversarial security review.
- [ ] Black-box actual HTTP cookie/session/mutation flow; kill Node and ensure worker releases lock; run packaged-mode smoke after packaging changes with isolated MONO_HOME. Checkpoint before library writes are exposed.

### CORE-2: durable library and recovery

**Files:** Create launcher/local_core/library.py, launcher/local_core/paths.py, launcher/local_core/schema.sql, launcher/tests/test_library.py, launcher/tests/test_library_recovery.py; Extend CORE-1 routes/client.
**Interfaces:** `Library.open(root:Path)->Library`; `create_record(meta)->Record`; `commit_segment(record_id,track,index,staged_file,duration_frames,sha256)->CommitReceipt`; `patch_record(id,expected_version,patch)->Record`; `list_records(cursor,limit,query)->Page`; `audio_descriptor(id,variant)->ReadDescriptor`; `recover()->RecoveryReport`. Receipt `{recordId,track,index,sha256,committedFrames,version}` only after file and metadata durability.

DTO definitions owned by this task: `Record={id:UUID,title:string,createdAt:ISO8601,duration:number,mime:string,size:integer,source:string,status:string,version:integer,tracks:TrackDescriptor[],transcript?:existingTranscriptShape,jobId?:UUID,job?:existingJobShape}`; other optional existing job/billing/prompt fields are preserved by explicit allowlist from current app.js. `Page={items:Record[],nextCursor:string|null}`; `ReadDescriptor={opaqueId:UUID,mime:string,size:integer,duration:number,rangeCapable:true}`; `RecoveryReport={recovered:UUID[],interrupted:UUID[],corrupt:UUID[],orphans:integer}`. `TrackDescriptor={id:string,sampleRate:integer,channels:integer,frames:integer,segmentCount:integer,gaps:{start:number,end:number,reason:string}[]}`. Cursor contains an opaque stable sort key, not a filesystem path. SQL schema and worker validators define these fields once; JS client adapts wire data without inventing a second persistence schema.

- [ ] RED fixtures: real SQLite + files; injected process death after temp write/fsync/rename/SQL commit, missing chunk, corrupt checksum, competing worker lock, full/read-only/missing disk and duplicate segment. Assert every acknowledged segment survives, duplicate same hash is idempotent, different hash same index conflicts, unacknowledged orphan is recoverable but not silently trusted.
- [ ] Implement library layout `library.sqlite3`, `library.json`, `records/<uuid>/original/`, `transcripts/`, `derived/`, `journal/`, `trash/`; allowlisted relative IDs only. SQLite WAL/synchronous FULL with explicit filesystem flushing strategy per OS; record manifests/journal independently support index rebuild. Schema version 1 rejects newer versions without modifications. One writer lock is library-scoped, not just launcher-scoped.
- [ ] Add transactional transcript original/edits with optimistic version and tombstones; later async job cannot resurrect a trashed record. No-success paths leave original files and a diagnosable state; partial sources carry gap metadata.
- [ ] Run `python -m unittest discover -s launcher/tests -p 'test_library*.py' -v`. Black-box reopen in a fresh worker and independently hash/decode committed audio files; rebuild a copied index and compare records/texts. Checkpoint.
