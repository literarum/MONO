## Что проверить нельзя без вас (НЕТ ДАННЫХ ДЛЯ НАДЁЖНОГО ВЫВОДА)

- **Ваш конкретный компьютер.** CI — это Windows Server 2025 с виртуальным кабелем. Реальные драйверы (Realtek, USB-гарнитуры, Bluetooth HFP) там не проверить. Если запись не пойдёт, нажмите «Настройки → Предполётная проверка → Скопировать диагностику» — там будет точный код ошибки Windows.
- **Значок в трее** не сделан: его нужно проверять на настоящем рабочем столе.
- **Подпись установщика** включится, когда в секреты репозитория будет добавлен сертификат.
- **Глобальная клавиша Ctrl+Alt+R**: код и маршрут проверены тестами. Сама регистрация `RegisterHotKey` в CI не проверяется: там нет интерактивного рабочего стола.

## Источники

- `AUDCLNT_E_DEVICE_IN_USE` возникает только при монопольном режиме: https://learn.microsoft.com/en-us/windows/win32/api/audioclient/nf-audioclient-iaudioclient-initialize
- `E_ACCESSDENIED` из `IAudioClient::Initialize` при запрете микрофона (наблюдение Mozilla): https://bugzilla.mozilla.org/show_bug.cgi?id=1752163
- Переключатель «Разрешить классическим приложениям доступ к микрофону»: https://support.microsoft.com/en-US/Windows/privacy/turn-on-app-permissions-for-your-microphone-in-windows
- Ключи `ConsentStore\microphone` (`Allow`/`Deny`) — сторонний разбор, не официальный документ Microsoft: https://www.elevenforum.com/t/enable-or-disable-apps-access-to-microphone-in-windows-11.17117/
- Тихая установка VB-CABLE: https://forum.vb-audio.com/viewtopic.php?p=7129
- `NotReadableError` getUserMedia: https://blog.addpipe.com/common-getusermedia-errors
- Контраст WCAG 2.x (4,5:1 для текста, 3:1 для элементов интерфейса): https://www.w3.org/TR/WCAG21/#contrast-minimum
