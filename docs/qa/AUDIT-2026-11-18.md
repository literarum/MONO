## Что проверить нельзя без вас (НЕТ ДАННЫХ ДЛЯ НАДЁЖНОГО ВЫВОДА)

- **Ваш конкретный компьютер.** CI — это Windows Server 2025 с виртуальным кабелем. Реальные драйверы (Realtek, USB-гарнитуры, Bluetooth HFP) там не проверить. Если запись не пойдёт, нажмите «Настройки → Предполётная проверка → Скопировать диагностику» — там будет точный код ошибки Windows.
- **Значок в трее** не сделан: его нужно проверять на настоящем рабочем столе.
- **Подпись установщика** включится, когда в секреты репозитория будет добавлен сертификат.
- **Глобальная клавиша Ctrl+Alt+R**: код и маршрут проверены тестами. Сама регистрация `RegisterHotKey` в CI не проверяется: там нет интерактивного рабочего стола.

## Раунд 2 — по фотографиям с ноутбука (USB-гарнитура, Windows)

| # | Что было на фото | Причина (как доказано) | Исправление |
|---|---|---|---|
| 1 | Выпадающий список «Микрофон браузера ✓» оторван от поля и висит внизу экрана | Правило `.glass{position:relative}` из glass.css перебивало `position:fixed` у списка (у него тоже класс `glass`), и список падал в конец документа | Правило карточек больше не трогает `position`; у списка нет класса `glass`. На снимке список открывается ровно под полем |
| 2 | Интерфейс «с низким fps» | Студия: волна и индикатор перерисовывались каждый кадр через `width` и текст — **~20 пересчётов раскладки и ~180 мс главного потока в секунду** (CPU ×4); наблюдатели DOM пересканировали документ при каждом обновлении текста | Индикатор двигается через `transform`, число обновляется не чаще 5 раз/с, волна — ≤30 кадров/с и только при изменении. **66 мс/с, 1 пересчёт/с, сдвигов раскладки — 0** |
| 3 | Полноэкранное размытие под листами | Под непрозрачными на 95 % листами размытие невидимо, но стоит полного прохода GPU в каждом кадре | Убрано. Регулятор качества: если на этом ПК кадры медленные, стекло само становится сплошным материалом |
| 4 | Поля скруглены некрасиво | Общая переменная `--radius-control` = 999px (для кнопок-капсул) делала капсулами выпадающие списки и многострочные поля | Одна форма для всех полей: радиус 12 px (многострочные 14 px), высота 44 px, мягкая рамка, заметное кольцо фокуса |
| 5 | «Карточка в карточке» в настройках, моноширинные цифры, оторванная точка в заголовке | Вёрстка | Исправлено |
| 6 | Источник «Микрофон браузера» и ошибка «система не смогла открыть микрофон» | (а) Нативный модуль выходил при старте, если **хотя бы одно** звуковое устройство в системе отвечало ошибкой; MONO оставался только с браузерным каналом. (б) Браузер получал `NotReadableError`: устройство держит другое приложение (на фото в трее значок «микрофон используется») | (а) Перечисление пропускает сбойное устройство; при полном отказе модуль остаётся жив и сообщает причину. (б) MONO называет приложение, которое сейчас держит микрофон (журнал Windows ConsentStore; эвристика). Предпросмотр уровня освобождает микрофон до старта записи; повторы браузерного канала дольше (300 мс, 1,2 с) |
| 7 | — | Некоторые драйверы USB/Bluetooth отклоняют обычный запрос на открытие потока | Вторая попытка через встроенный конвертер Windows (`AUTOCONVERTPCM`, буфер 200 мс). Отказ доступа, монопольный режим и пропажа устройства не повторяются |

**НЕТ ДАННЫХ ДЛЯ НАДЁЖНОГО ВЫВОДА**, какая из причин 6–7 сработала именно на вашем ноутбуке: подключить его к сессии было нельзя, а кода ошибки Windows на фото нет. После обновления точный код покажет «Настройки → Предполётная проверка → Скопировать диагностику».
