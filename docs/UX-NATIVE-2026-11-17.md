## UX-брейншторм (следующие шаги)

### Первый запуск и установка
1. **Подписанный установщик** (Authenticode), чтобы SmartScreen не пугал. Нужен сертификат — решение владельца.
2. **Автообновление:** проверка релиза при запуске и установка поверх с сохранением данных.
3. **Мастер первого запуска в три экрана:** «Папка (по умолчанию „Документы“) → Микрофон (живой индикатор уровня) → Groq (можно позже)». Каждый экран пропускается.
4. **Тестовая запись 5 с с прослушиванием** прямо в мастере.
5. **Импорт старого архива** из Chrome/IndexedDB одной кнопкой (миграция уже есть — вывести её в мастер).

### Запись — главное действие
6. **Индикатор уровня до старта:** «Говорите — шкала должна двигаться».
7. **Глобальная горячая клавиша записи и значок в трее.**
8. **Маркер «Важно» во время записи** — одна клавиша.
9. **Режим «Встреча»:** две дорожки (Я / Собеседники) с подписями спикеров без ML.
10. **Продолжение записи после смены устройства** вместо остановки.
11. **Предупреждение о разряде батареи ноутбука** во время долгой записи.

### Liquid Glass — дальше
12. **Плавающий мини-плеер** над контентом (стекло, капсула) в редакторе.
13. **«Scroll edge effect»** — затемнение контента под плавающей панелью при прокрутке.
14. **Морфинг кнопки «Начать» → «Пауза | Стоп»** (одна капсула делится на две).
15. **Цветовой акцент для светлой и тёмной темы по системным настройкам Windows** (accent color).
16. **Компактный обзор:** последние записи и кнопка записи вместо рекламного баннера.

### Дружелюбность и понятность
17. **Ошибки с действием:** каждое сообщение — что случилось, что сохранено, кнопка «Исправить».
18. **Пустые состояния с одной кнопкой:** «Нет записей → Записать».
19. **Подсказки при наведении для всех значков**, полное имя вкладки — в подписи.
20. **Отмена удаления** (тост «Запись в корзине · Вернуть») вместо модального подтверждения.

### Надёжность, видимая пользователю
21. **«Чёрный ящик»:** кнопка «Скопировать диагностику» в предполётной проверке (без содержимого записей).
22. **Индикатор «Сохранено N секунд назад» во время записи.**
23. **Автоматическое восстановление прерванной записи** при следующем запуске с карточкой «Запись восстановлена».
